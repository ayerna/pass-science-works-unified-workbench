h = tanh(0.5) = 0.462117, loss = 1.182542. Gradients: dw = db = -1.209464, dv = -0.710682, dc = -1.537883. One step at lr 0.1: w = 0.620946, b = 0.120946, v = 1.071068, c = 0.153788. C++ verifies each gradient by central finite differences (eps 1e-6, error limit 1e-5) and writes results/backprop_loss.csv for 100 steps. The handwritten 2-page derivation itself must be written by the candidate, it is not generated here.

Performance: serial vs parallel batch

Bounded worker pool, fixed seed 42, identical cases and solver in both versions. File loading, rendering and compilation are excluded from compute timings. Launch-to-ready time is measured separately on the target machine and recorded in the report, it is not claimed here.

WorkersMedian (ms)SpeedupEfficiency
Run ./workbench batch to fill this table from results/performance.csv (served over http; file:// blocks fetch, so the CSV is the source of truth).

Agreement limit: serial vs parallel max temperature difference ≤ 1e-8 C. Overhead note: for small batches, thread creation and scheduling can outweigh the compute, so speedup below worker count is expected and honest, not a failure.
